# مرجع الصفحات ونقاط الـ Backend

جميع الروابط تبدأ من `http://localhost/STD/`.

## 1. الصفحات العامة

| الصفحة | الملف | الوصف |
|---|---|---|
| الرئيسية | `index.php` | شريط التنقل، وقسم ترحيبي، وشريط إحصائيات، وبطاقات المميزات، ونبذة عن الجامعة والعمادة، وقسم الفريق، ودعوة للتسجيل، وتذييل |
| عن النظام | `about.php` | تعريف بالنظام، وجامعة بيشة، ومهام العمادة، و6 أهداف للمشروع، وشارات التقنيات، وبطاقات الفريق |
| تسجيل الدخول | `login.php` | تبويب **طالب** (البريد أو الرقم الجامعي) وتبويب **موظف** (البريد). يُرسل إلى `backend/login.php` |
| إنشاء حساب | `signup.php` | البيانات الشخصية (الاسم، ورقم الهوية، والجنس، والجوال)، والبيانات الأكاديمية (الكلية، والدرجة، والتخصص، والمرشد في قوائم متتابعة)، وبيانات الحساب (البريد، وكلمة المرور وتأكيدها). يُرسل إلى `backend/register.php` |

## 2. صفحات الطالب (`student/`)، محمية بـ `requireStudent()`

| الصفحة | الملف | الوظيفة |
|---|---|---|
| الرئيسية | `dashboard.php` | بانر ترحيب، وإحصائيات الطلبات، وآخر الطلبات، وإجراءات سريعة، وخدمات مميزة |
| المساعد الذكي | `chatbot.php` | نافذة محادثة وبجانبها آخر 10 محادثات. افتح محادثة سابقة بـ `?conv=ID` أو ابدأ محادثة جديدة. تستخدم كائن `Chatbot` من `main.js` |
| الخدمات | `services.php` | بطاقات الخدمات مع تصفية حسب القسم وبحث. الرابط `?id=` يعرض التفاصيل: الشروط، والمستندات المطلوبة، والخطوات، وزر تقديم الطلب |
| الأدلة والنماذج | `guides.php` | تبويبان (الأدلة / النماذج) مع بحث وتحميل الملفات |
| الأسئلة الشائعة | `faq.php` | قائمة منسدلة (أكورديون) بالأسئلة المنشورة |
| طلباتي | `my_requests.php` | قائمة طلبات الطالب مع شارات الحالة والأولوية |
| طلب جديد | `new_request.php?service_id=` | نموذج طلب للخدمة المختارة: العنوان، والوصف، والأولوية، والمرفق |
| تفاصيل الطلب | `request_details.php?id=` | بيانات الطلب، والمرفق، وسلسلة الردود، ونموذج الرد. لا يفتحها إلا صاحب الطلب |
| الملف الشخصي | `profile.php` | تعديل البيانات الشخصية والأكاديمية، ورفع صورة شخصية، وتغيير كلمة المرور |

في شريط التنقل العلوي روابط سريعة للطالب إلى: الخدمات، والأدلة والنماذج، والأسئلة الشائعة.

## 3. صفحات الإداري (`admin/`)، محمية بـ `requireAdmin()` (الإداري أو المدير)

| الصفحة | الملف | الوظيفة |
|---|---|---|
| لوحة التحكم | `dashboard.php` | إحصائيات، وتقدّم توليد المتجهات، وآخر الطلبات، وآخر محادثات الشات بوت، والطلبات حسب الحالة |
| الطلبات | `requests.php` | قائمة الطلبات مع التصفية وترقيم الصفحات |
| تفاصيل الطلب | `request_details.php?id=` | سلسلة الردود، ونموذج الرد، ونموذج تحديث الحالة والأولوية والمُسنَد إليه |
| الخدمات | `services.php` | إضافة الخدمات وتعديلها وحذفها (نافذة منبثقة)، ومعها حقل التوجيه `assigned_role` |
| الأدلة | `guides.php` | إضافة وتعديل وحذف مع رفع ملف |
| النماذج | `forms.php` | إضافة وتعديل وحذف مع رفع ملف |
| الأسئلة الشائعة | `faq.php` | إضافة وتعديل وحذف |
| قاعدة المعرفة | `knowledge_base.php` | إضافة وتعديل وحذف، وعدد المقاطع والمتجهات، وزر "إنشاء Embeddings" |
| مراجعة المحادثات | `chatbot_reviews.php` | قائمة المحادثات مع بحث وأعلى درجة ثقة. افتح محادثة بـ `?conv=` لقراءة رسائلها وحفظ تقييم |
| الأسئلة غير المُجابة | `unknown_questions.php` | إحصائيات (في الانتظار، وتمت المراجعة، وأضيفت للمعرفة)، وتصفية حسب الحالة، وزر "تمت المراجعة"، وزر "إضافة لقاعدة المعرفة" (نافذة مُعبّأة مسبقاً) |
| الملف الشخصي | `profile.php` | تعديل الملف الشخصي وتغيير كلمة المرور |

## 4. صفحات المدير (`manager/`)

محمية بـ `requireManager()` ما لم يُذكر غير ذلك. صفحات المحتوى نسخ من صفحات الإداري تعمل بقائمة المدير الجانبية.

| الصفحة | الملف | الحماية | الوظيفة |
|---|---|---|---|
| لوحة التحكم | `dashboard.php` | مدير | عدد المستخدمين لكل دور (مبني من `user_types`)، وإحصائيات الطلبات، والطلبات حسب الحالة، وآخر الطلبات، وآخر المستخدمين |
| الطلاب | `students.php` | مدير | بحث بالاسم أو البريد أو الرقم، وتصفية حسب الكلية أو الحالة، وترقيم صفحات، وإضافة وتعديل (`?edit=ID`)، وتعيين المرشد، وتفعيل أو إيقاف، وحذف |
| الإداريون | `admins.php` | مدير | إضافة الإداريين وتعديلهم وحذفهم |
| المرشدون الأكاديميون | `advisors.php` | مدير | إضافة وتعديل وحذف (`save_advisor.php` و`delete_advisor.php`) |
| الكليات | `colleges.php` | مدير | إضافة وتعديل وحذف |
| الدرجات العلمية | `degrees.php` | مدير | إضافة وتعديل وحذف |
| التخصصات | `majors.php` | مدير | إضافة وتعديل وحذف، وكل تخصص مرتبط بكلية ودرجة |
| الأقسام | `departments.php` | مدير | إضافة وتعديل وحذف |
| أنواع المستخدمين | `user_types.php` | مدير | إضافة وتعديل وحذف الأدوار والفئات |
| الطلبات | `requests.php` و `request_details.php` | إداري | مثل صفحات الإداري |
| الخدمات | `services.php` | إداري | مثل صفحة الإداري |
| الأدلة والنماذج والأسئلة الشائعة وقاعدة المعرفة | `guides.php` و `forms.php` و `faq.php` و `knowledge_base.php` | إداري | مثل صفحات الإداري |
| مراجعة المحادثات | `chatbot_reviews.php` | مدير | مثل صفحة الإداري |
| **محاضر الاجتماعات** | `meetings.php` | إداري أو مرشد | قائمة الاجتماعات مع تقدّم التوصيات. الإداري والمدير يضيفان ويعدّلان ويحذفان |
| **تفاصيل الاجتماع** | `meeting_details.php?id=` | إداري أو مرشد | بيانات الاجتماع، وبطاقات التوصيات (القرار، ونوع الدعم، والمبلغ، والصرف)، وشريط جانبي بالملخص، ونافذة إضافة التوصية |
| التقارير | `reports.php` | مدير | تحليلات (انظر README القسم 3.9) |
| الإعدادات | `settings.php` | مدير | الإعدادات العامة والشعار والذكاء الاصطناعي، وحالة المتجهات |
| الملف الشخصي | `profile.php` | مدير | تعديل الملف الشخصي |

قائمة المدير الجانبية فيها أيضاً رابط إلى `admin/unknown_questions.php`.

## 6. نقاط الـ Backend (`backend/`)

كل نقاط POST تتحقق من رمز CSRF ما لم يُذكر غير ذلك، وتعيد التوجيه إلى صفحة مع رسالة فلاش. نقطة الشات بوت وحدها تُرجع JSON.

### المصادقة والحساب
| النقطة | الطريقة | المستخدم | الغرض |
|---|---|---|---|
| `login.php` | POST | عام | التحقق من الهوية والتوجيه حسب الدور. لا يوجد فحص CSRF |
| `register.php` | POST | عام | إنشاء حساب طالب |
| `logout.php` | GET | الجميع | إنهاء الجلسة |
| `update_profile.php` | POST | مسجّل دخول | تحديث الملف الشخصي والصورة وكلمة المرور، وللطالب حقول أكاديمية إضافية |
| `mark_notifications_read.php` | GET | مسجّل دخول | تحديد كل إشعارات المستخدم كمقروءة |

### الطلبات
| النقطة | المستخدم | الغرض |
|---|---|---|
| `save_request.php` | طالب | تقديم طلب وتوجيهه وإرسال الإشعارات |
| `save_reply.php` | طالب / موظف | إضافة رد (تصبح الحالة `replied` إذا ردّ الموظف) وإرسال الإشعارات |
| `update_request_status.php` | إداري / مدير / مرشد | تغيير الحالة والأولوية. تغيير المُسنَد إليه للإداري والمدير فقط |

### المحتوى وقاعدة المعرفة
| النقطة | المستخدم | الغرض |
|---|---|---|
| `save_service.php` | إداري فأعلى | إضافة خدمة أو تعديلها ومزامنتها مع قاعدة المعرفة |
| `save_guide.php` | إداري فأعلى | إضافة دليل أو تعديله مع ملف، ومزامنته مع قاعدة المعرفة (مع رابط التحميل) |
| `save_form.php` | إداري فأعلى | إضافة نموذج أو تعديله مع ملف، ومزامنته مع قاعدة المعرفة (مع رابط التحميل) |
| `save_faq.php` | إداري فأعلى | إضافة سؤال شائع أو تعديله ومزامنته مع قاعدة المعرفة |
| `save_knowledge.php` | إداري فأعلى | إضافة مدخل معرفة أو تعديله، وإعادة بناء المقاطع وتوليد متجهاتها فوراً. المعامل الاختياري `uq_id` يغلق سؤالاً غير مُجاب |
| `generate_embeddings.php` | إداري فأعلى (GET) | توليد متجهات حتى 50 مقطعاً معلّقاً |
| `delete_item.php?type=&id=&csrf=` | إداري فأعلى / مرشد (انظر ARCHITECTURE القسم 6، المشكلة 13) | حذف عام للأنواع: service و guide و form و faq و knowledge و user و college و degree و major و user_type و department و meeting و recommendation |

### الشات بوت
| النقطة | المستخدم | الغرض |
|---|---|---|
| `chatbot_process.php` | مسجّل دخول (POST، JSON) | إجابة RAG. الحقول: `message` و`conversation_id`. الاستجابة: `{answer, suggest_request, conversation_id}` |
| `save_review.php` | إداري فأعلى | تقييم محادثة |
| `mark_unknown_reviewed.php` | إداري فأعلى | تحويل حالة سؤال غير مُجاب إلى `reviewed` |
| `test_gemini.php` | مدير | صفحة تشخيص لـ Gemini API |

### المستخدمون والبنية (المدير)
| النقطة | الغرض |
|---|---|
| `save_user.php` | إضافة طالب أو إداري أو تعديله |
| `save_advisor.php` / `delete_advisor.php` | إضافة مرشد أو تعديله أو حذفه (مع التحقق من عدم تكرار البريد ورقم الهوية) |
| `toggle_user_status.php` | التبديل بين نشط وموقوف |
| `save_college.php` و `save_degree.php` و `save_major.php` و `save_department.php` و `save_user_type.php` | إدارة البنية الأكاديمية |
| `save_settings.php` | حفظ الإعدادات، أو رفع الشعار وحذفه (`action=upload_logo`) |

### الاجتماعات
| النقطة | المستخدم | الغرض |
|---|---|---|
| `save_meeting.php` | إداري فأعلى / مرشد | إضافة اجتماع أو تعديله |
| `save_recommendation.php` | إداري فأعلى / مرشد | إضافة توصية أو تعديلها، وإعادة حساب حالة الاجتماع |

### الترحيل (تُشغَّل مرة واحدة)
`migrate.php` و `migrate_advisor.php` و `migrate_meeting_tables.php` و `migrate_requests.php` و `migrate_unknown_questions.php`. لا حاجة لها بعد استيراد `std_system.sql`.

## 7. الملفات المشتركة (includes)

| الملف | أهم الدوال |
|---|---|
| `includes/db.php` | `$pdo`، و`getSetting($key, $default)` |
| `includes/auth.php` | `isLoggedIn` و`getUserType` و`getUserId` و`isStudent/isAdmin/isManager/isAdvisor` و`require*` و`loginUser` و`logoutUser` و`redirectByRole` |
| `includes/functions.php` | `clean` و`setFlash/getFlash/showFlash` و`logActivity` و`sendNotification` و`getUnreadNotifications` و`getLatestNotifications` و`requestStatusLabel` و`priorityLabel` و`knowledgeTypeLabel` و`formatDate(Time)` و`uploadFile` و`formatChatMessage` و`splitIntoChunks` و`cosineSimilarity` و`findRelevantChunks` و`generateCsrfToken/validateCsrfToken` و`getUserAvatar` و`paginate` و`renderPagination` |
| `includes/gemini.php` | `class GeminiAPI { generateEmbedding(), generateAnswer(), callApi() }` |
| `includes/header.php` | رأس الصفحة، وشريط التنقل، والإشعارات، وقائمة المستخدم، واستدعاء القائمة الجانبية، وعرض رسائل الفلاش |
| `includes/sidebar.php` | قائمة لكل دور، وتمييز الرابط النشط، وشارة عدد الأسئلة غير المُجابة |
| `includes/footer.php` | إغلاق التخطيط وتحميل السكربتات |
